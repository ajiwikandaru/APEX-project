Project APEX: Kalkulator Dosis dari Peta Lokasi

1. Upload peta lokasi

Upload peta untuk menampilkan pratinjau. Pembacaan otomatis membutuhkan Anthropic API key; tanpa API key, Anda tetap bisa mengisi tabel atau mengimpor angka luas.
Pengaturan API Claude (opsional)

Untuk pengujian lokal saja. Jangan masukkan API key ke website publik atau commit ke GitHub. Key tidak disimpan ke Local Storage, tetapi tetap dapat diakses dari browser selama halaman terbuka. Pembacaan AI mengirim gambar peta ke Anthropic.

2. Atur dosis dan kapasitas ritase

Formula: target dosis per plot = luas plot (ha) × dosis (ton/ha). Ritase desimal = target ton per plot ÷ kapasitas Baldan. Ritase bulat dibulatkan ke atas untuk setiap plot.
